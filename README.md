# LeetCode Solutions 🧠

A collection of my **daily LeetCode problem-solving practice**.

The goal isn't just to solve problems — it's to **think better, recognize patterns, write cleaner code, and get a little better every day.**

> **Solve. Learn. Repeat. 🚀**

## 📂 Structure

Each problem lives in its own directory, named after the original LeetCode problem slug.

```text

│   └── main.go

```

## 🎯 What You'll Find
